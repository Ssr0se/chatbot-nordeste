# 🌴 Nordeste Viagens - Chatbot

## Sobre o projeto

Chatbot desenvolvido para uma agência de turismo,
com o objetivo de fornecer informações aos clientes
interessados em viagens para o Nordeste brasileiro.

## Funcionalidades

- Consulta de destinos;
- Informações sobre viagens;
- Consulta de pacotes;
- Perguntas frequentes;
- Atendimento automatizado.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- GitHub
- GitHub Pages

## Destinos disponíveis

- Maceió
- Recife
- Natal
- Fortaleza
- Salvador

## Como executar

Abra o arquivo index.html em um navegador.

## Publicação

O projeto está disponível através do GitHub Pages.
